Smash Bender

Smash Bender is a processing server for song mashups, with scripts for the phone. It is for the person building the smash tools.

The server splits a song into vocals and music, reads the melody, bends one vocal onto the timing and notes of another, and mixes the result. Word timing comes from the real lyrics, so each word is cut on its true edges. Helper scripts on the phone start jobs and download the results, and a scorer checks how well the words matched.

Latest change. 2026-10-29, v2026.10.29. Word timing now uses the real lyrics and a word map, so the second song is cut on real word edges and sung on the first song's timing and notes. Songs can be uploaded from the phone, a short job starter and a downloader were added, and a scorer matches words by content.
